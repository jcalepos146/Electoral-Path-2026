To regenerate data/historical-generic.json, place these eleven RealClearPolling PDF exports in this folder:

2004 Generic Congressional Vote _ RealClearPolling.pdf
2006 Generic Congressional Vote _ RealClearPolling.pdf
2008 Generic Congressional Vote _ RealClearPolling.pdf
2010 Generic Congressional Vote _ RealClearPolling.pdf
2012 Generic Congressional Vote _ RealClearPolling.pdf
2014 Generic Congressional Vote _ RealClearPolling.pdf
2016 Generic Congressional Vote _ RealClearPolling.pdf
2018 Generic Congressional Vote _ RealClearPolling.pdf
2020 Generic Congressional Vote _ RealClearPolling.pdf
2022 Generic Congressional Vote _ RealClearPolling.pdf
2024 Generic Congressional Vote _ RealClearPolling.pdf

Then run: npm run rebuild-history

The generated historical JSON is already included, so the PDFs are not required to build or deploy the website.
